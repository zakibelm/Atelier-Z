Source d'IA

D'où viennent les modèles de tes agents ?

Les identifiants de modèles ne sont pas les mêmes d'une source à l'autre : après un changement, rechoisis le modèle de chaque agent, ou applique le même à tous ci-dessous.

Passerelle OmniRoute

Statut non configurée

Si OmniRoute tourne sur le même VPS, utilise son adresse locale ou Tailscale : rien n'est exposé sur Internet. La clé est enregistrée dans le dossier de données d'OpenMausBot et n'est jamais réaffichée. L'adresse se termine en général par /v1.

Clé OpenRouter

Statut non configurée

La clé est enregistrée dans le dossier de données d'OpenMausBot, sur ta machine. Elle n'est jamais écrite dans le dépôt et n'est plus jamais affichée. Pour limiter les risques, crée une clé avec un plafond de dépenses dans ton compte OpenRouter.
