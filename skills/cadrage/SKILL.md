# Cadrage

## Fiche de mission
- Client, secteur, zone géographique, site et réseaux
- **Objectif principal** : notoriété, ventes ou rendez-vous (un seul, les autres en secondaire). Il pondère tout le reste.
- Cible et offre principale
- Contraintes : budget, délai, langue, conformité (Loi 25, CASL pour le Québec)
- Livrable attendu et destinataire
- Mode de travail suggéré pour chaque phase

## Méthode
1. Poser au maximum quelques questions groupées, seulement sur ce qui change le résultat ; le reste est déduit et marqué comme hypothèse.
2. Si le client a un site ou des profils, lancer une lecture rapide pour confirmer le type d'entreprise et les pages clés.
3. Publier la fiche dans le salon pour validation de l'utilisateur.

## Sortie
Fiche de mission validée, épinglée dans le tableau d'état.
