# Règles du salon

## Prise de parole

- Silence par défaut. Un agent intervient seulement s'il est interpellé (`@nom`), si le sujet relève de son domaine, ou s'il repère une erreur.
- L'utilisateur peut interrompre et interpeller à tout moment.
- Le chef d'atelier modère : il coupe les échanges qui tournent en rond et tranche.

## Garde-fous

- Plafond de tours et de jetons par discussion et par mission. Raison : éviter que des agents qui se répondent entre eux fassent grimper les coûts.
- Source obligatoire pour tout constat chiffré ou vérifiable. Le vérificateur bloque le reste.
- Les décisions sont épinglées dans le tableau d'état et rappelées aux agents.
- Chaque agent se relit avant de rendre son travail.
- Actions risquées (envoi, modification, suppression) : approbation humaine obligatoire.
- Rien n'est envoyé à un client sans validation de l'utilisateur.

## Cycle de travail

1. Première passe en séquence : cadrage → recherche → vérification → stratégie.
2. Discussion libre dans le salon.
3. Travaux lancés à la demande, en séquence ou en parallèle.
4. Résultats publiés dans le fil, décisions épinglées.
5. Sur demande : rapport PDF avec recommandations et plan d'action.

## Seuil de qualité

Le but n'est pas la perfection : le message passe, la logique tient, rien ne choque.
