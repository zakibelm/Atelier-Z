# Rôles de l'équipe

Chaque agent a une description claire (c'est elle qui dit aux autres ce qu'il fait), un ou plusieurs skills, et des connexions limitées à son besoin.

Les skills de chaque rôle sont dans le dossier [skills/](../skills/) (un dossier par skill, avec un `SKILL.md`). Le chef d'atelier (chef d'équipe) et l'orchestrateur (expert en répartition du travail) travaillent ensemble : le premier anime le salon, le second planifie et délègue.

| Agent | Rôle | Skills (exemples) | Connexions |
|---|---|---|---|
| Chef d'atelier | Seul à parler à l'utilisateur, modère le salon, choisit le mode, lance les travaux | Choix du mode, suivi des tâches, arbitrage | Tableau d'état |
| Cadrage | Demande l'objectif du client (notoriété, ventes, rendez-vous) et le contexte, pondère le reste | Fiche de mission | Drive |
| Chercheur site et technique | Métadonnées, structure, prix et informations incohérentes entre pages | Audit technique | Lecture web, Search Console |
| Chercheur contenu et message | Clarté, conversion, preuves sociales | Audit contenu | Lecture web |
| Chercheur concurrents | Concurrents directs, indirects, aspirationnels | Analyse concurrentielle | Recherche web |
| Chercheur audience (et GEO, optionnel) | Audience, présence dans les moteurs d'IA | Analyse audience | Recherche web, GA4 |
| Vérificateur | Recontrôle chaque constat critique à la source, bloque ce qui n'a pas de source | Vérification des sources | Recherche web |
| Stratège | Synthèse (SWOT), options, priorités, plan d'action | Synthèse stratégique | Tableau d'état |
| Rédacteur | Compile décisions et plan en rapport PDF | Génération de rapport | Export PDF |

## Principes (méthode des 4 C)

- Contexte : description de rôle précise, informations client et objectifs.
- Connexions : accès limité au strict nécessaire, en lecture d'abord.
- Capacités : un skill par livrable, mis à jour après chaque retour de l'utilisateur.
- Cadence : re-audit périodique avec comparaison avant et après.
